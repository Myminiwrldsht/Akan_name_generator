# Akan_name_generator

##Project Name

Akan Name Generator
--- 

##Project Description

This is a simple web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender.
These "day names" have further meanings concerning the soul and character of the person. Middle names have considerably more variety and can refer to their birth order, twin status, or an ancestor's middle name.

> <a href= "https://en.wikipedia.org/wiki/Akan_names"> Learn more on Akan names and their origin story </a>

##BDD (Behaviour-Driven Development)


| Behavior | Input | Output |
|----------|-------|--------|
| User enters valid birth date and selects gender | 15 / 8 / 2003 + female | Your Akan name is: Ama |
| User enters invalid day | 35 | Alert: "Please enter a valid day (1-31)" |
| User enters invalid month | 13 | Alert: "Please enter a valid month (1-12)" |
| User does not select gender | empty | Alert: "Please select a valid gender" |
